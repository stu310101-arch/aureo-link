Windows 10 / 11 x64 · 安裝精靈 · 桌面捷徑 · 無需安裝 Python

01

開啟電腦程式

執行安裝精靈，保留「建立桌面捷徑」勾選。完成後從桌面開啟 Amos電腦手機連結器。

02

手機掃碼配對

手機 App 安裝一次，即可在 App 內掃碼或輸入 8 位數，並在電腦確認配對。

03

在線即可傳送

雙方保持在線，即可傳檔並查看進度。單檔上限 20 MiB。

固定 App，重新開啟即可連線

手機 App 固定在這個網站，加入主畫面一次即可長期使用。電腦網址改變時，App 會尋找並驗證已配對的電腦，不需要重新安裝 PWA。使用者自己的電腦仍須開機、連網並開著程式。

從舊的臨時網址 PWA 升級，請改用固定手機 App 一次。免費配對服務首次喚醒可能需要約一分鐘。iPhone 剪貼簿仍需點按操作；目前沒有端對端加密。
